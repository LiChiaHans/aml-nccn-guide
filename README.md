# AML 急性骨髓性白血病 — NCCN v5.2026 臨床速查網頁

整理並翻譯自 **NCCN Clinical Practice Guidelines in Oncology: Acute Myeloid Leukemia (Age ≥18 years), Version 5.2026 (July 15, 2026)**。

## 線上連結 (GitHub Pages)

## 功能特色
- **章節快速查找側邊欄**：對應原版 NCCN 頁碼（`EVAL-1/2`、`AML-1~9`、`AML-A~J`、`APL-1~6`、`BPDCN-1~4`）。
- **即時全文檢索與高亮**：快速搜尋基因（如 *FLT3*, *NPM1*, *IDH1*, *TP53*, *KMT2A*）、藥物（如 Venetoclax, Revumenib, Ziftomenib, Pivekimab）或急症處置。
- **互動式風險分層切換**：內建 ELN 2022（高強度化療）與 HMA + Venetoclax 預後分層切換。
- **深色 / 淺色模式**與**行動裝置響應式介面**，並支援列印格式。
